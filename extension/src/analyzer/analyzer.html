Check an email's source

The full source includes the sender checks (SPF, DKIM, DMARC) and Reply-To that webmail hides.

Gmail: open the email, click ⋮ → Show original, then Copy to clipboard. Outlook: ⋯ → View → View message source. Or drop an .eml file here.

The result shows up here.

Everything is checked inside your browser. The email is not uploaded anywhere.
